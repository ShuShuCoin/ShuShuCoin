**鼠鼠 / ShuShuCoin / SHUSHU** is an independent Scrypt proof-of-work blockchain derived from the stable Dogecoin Core `v1.14.9` release.

## Bootstrap status

The mainnet identity, issuance schedule, genesis block, data directories, executable names, address prefixes, P2P/RPC ports, and empty initial seed set are configured in this source tree. A Linux daemon build was completed and started against an empty dedicated data directory; its verified genesis hash is documented in `docs/shushucoin-chain-spec.md`.

## Executables

- `shushucoind`
- `shushucoin-cli`
- `shushucoin-tx`
- `shushucoin-qt`

## Provenance

ShuShuCoin retains the upstream MIT license and the required Bitcoin Core and Dogecoin Core attribution notices. This is a separate ledger and network, not the Dogecoin ledger.
